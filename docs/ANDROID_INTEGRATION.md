# ربط تطبيق شبكة الكامل وتطبيق الإدارة

## بروتوكول الخادم المحلي
- فحص الخدمة: \`GET /api/health\`
- الأقسام العامة الظاهرة: \`GET /api/public/sections\`
- تسجيل جهاز/استلام تحديثات: \`GET /api/poll?device=DEVICE_ID&since=LAST_MESSAGE_ID\`
- تسجيل دخول المدير: \`POST /api/login\` مع \`{"password":"..."}\`
- بقية مسارات الإدارة تتطلب \`Authorization: Bearer TOKEN\`.

## آلية Android المطلوبة
1. عند أول تشغيل، يحفظ التطبيق عنوان الخادم المحلي ومعرّف جهاز ثابتاً مولداً عشوائياً (ليس IMEI ولا رقم هاتف).
2. يجلب الأقسام من \`/api/public/sections\` ويعرض فقط العناصر التي يعرف التطبيق وجهتها. يلزم تنفيذ renderer/route registry داخل تطبيق شبكة الكامل؛ مجرد إرسال عنوان قسم من الخادم لا ينشئ شاشة وظيفية تلقائياً.
3. خدمة استقبال محلية تسأل \`/api/poll\` مع آخر message id محفوظ وتعرض Android Notification لكل رسالة جديدة.
4. عند التطبيق مغلقاً، يلزم Android Foreground Service بإشعار دائم أو آلية موثوقة متوافقة مع إصدار Android وسياسات البطارية. قد يمنع النظام التنفيذ في بعض الظروف إذا لم تُمنح الصلاحيات.
5. لا تستخدم FCM في وضع LAN-only؛ فهو يتطلب اتصالاً بخدمات Google عبر الإنترنت.

## أمن
- لا تضمّن كلمة مرور المدير في تطبيق المشتركين.
- لا تستخدم عنوان IP أو MAC كهوية آمنة للمستخدم.
- أضف مصادقة جهاز/مفتاح تسجيل قبل السماح للأجهزة باستلام الرسائل الخاصة.
- النسخة الحالية تأسيسية؛ يلزم إكمال مصادقة الأجهزة وتشفير الاتصال قبل نشرها على شبكة إنتاجية.
