# تطبيق Android – المرحلة الأولى
- الحزمة: `com.alkamel.admin`
- minSdk 24 / targetSdk 35
- ضبط عنوان خادم Windows 10 المحلي وتسجيل دخول المدير.
- عرض إحصائيات الخادم.
- إضافة قسم وإظهار/إخفاء الأقسام.
- إرسال رسالة عامة وحفظها بالخادم.

هذه نسخة إدارة أولية. لا تحتوي بعد على استقبال إشعارات للمشتركين في الخلفية، ولا إدارة المشرفين أو المستخدمين. إنشاء قسم في لوحة الإدارة لا يظهر داخل تطبيق المشتركين إلا بعد إضافة تكامل واجهة الأقسام في مشروع شبكة الكامل نفسه.
