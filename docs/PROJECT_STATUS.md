# حالة التطوير

## المرحلة 0.1.0 – تأسيس الخادم ولوحة الويب
- [x] مستودع مستقل.
- [x] خادم Python محلي بلا مكتبات خارجية.
- [x] قاعدة بيانات SQLite دائمة.
- [x] إدارة الأقسام وإظهارها/إخفاؤها.
- [x] إرسال الرسائل وحفظها.
- [x] نقطة polling لتسليم الرسائل للأجهزة المتصلة.
- [x] لوحة ويب عربية RTL.
- [x] سجل العمليات والإحصائيات الأساسية.
- [x] ملفات تشغيل ونسخ احتياطي لـ Windows 10.
- [x] اختبارات API وCI.

## المراحل التالية
1. إنشاء تطبيق Android مستقل وتوصيله بالخادم المحلي.
2. بناء خدمة Android لاستقبال الرسائل وإظهار الإشعارات في الخلفية مع مراعاة قيود Android الحديثة.
3. ربط الأقسام ديناميكياً بتطبيق شبكة الكامل الحالي (يتطلب تعديل تطبيق المشتركين لإضافة نقاط عرض آمنة للأقسام).
4. إضافة إدارة المشرفين وصلاحياتهم، وتسجيل الأجهزة.
5. تحسين الأمان: كلمات مرور مخزنة بتجزئة قوية، تدوير الجلسات، حماية محاولات الدخول، وتوثيق الأجهزة.
6. اختبار التكامل على شبكة الكامل وخادم Windows 10 الفعلي.

**ملاحظة:** الإصدار الحالي ليس APK نهائياً، ولا يدّعي إرسال إشعار Android فورياً قبل دمج تطبيق Android وخدمة استقبال الأجهزة.
