# تشغيل الخادم على Windows 10
- انسخ المشروع إلى جهاز الخادم.
- ثبّت Python 3.10+.
- شغّل \`server\run-server.bat\`.
- اسمح للمنفذ TCP/8080 في جدار حماية Windows على ملف تعريف الشبكة الخاصة فقط.
- اعرف عنوان IP المحلي للجهاز عبر \`ipconfig\`.
- من أي جهاز داخل شبكة الكامل افتح \`http://عنوان-الخادم:8080\`.
- غيّر كلمة مرور المدير عبر متغير البيئة \`ALKAMEL_ADMIN_PASSWORD\` قبل التشغيل.
- خذ نسخة احتياطية دورية من مجلد \`server\data\` باستخدام \`server\backup.bat\`.

لا تفعّل تحويل منافذ الراوتر ولا تعرض الخادم على الإنترنت.
