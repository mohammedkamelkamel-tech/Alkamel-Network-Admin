# إدارة شبكة الكامل | Alkamel Network Admin

مشروع مستقل لإدارة تطبيق **شبكة الكامل** داخل الشبكة المحلية فقط.

## مكونات المشروع
- `server/`: خادم محلي على Windows 10 مع قاعدة بيانات SQLite دائمة وواجهة REST.
- `web/`: لوحة تحكم عربية RTL تعمل من المتصفح على الشبكة المحلية.
- `android/`: تطبيق إدارة Android (سيتم استكمال واجهاته وربطه بالخادم في المرحلة التالية).
- `windows/`: ملفات تشغيل الخادم والنسخ الاحتياطي.

## التشغيل الأولي على Windows 10
1. ثبّت Python 3.10 أو أحدث.
2. افتح مجلد `server` وشغّل `run-server.bat`.
3. افتح من جهاز متصل بالشبكة: `http://IP-OF-SERVER:8080`.
4. غيّر كلمة مرور المدير الافتراضية من ملف الإعدادات قبل الاستخدام الفعلي.

## وظائف النسخة الأولية
- إدارة أقسام التطبيق (إضافة، تعديل، إظهار، إخفاء، حذف).
- نشر رسائل وإعلانات للمشتركين المسجلين.
- سجل للرسائل والعمليات الإدارية.
- تخزين دائم في SQLite.
- واجهة ويب محلية.

## تنبيه مهم للإشعارات
الخادم المحلي لا يستطيع استخدام Firebase Cloud Messaging دون إنترنت. في وضع LAN، يستقبل تطبيق Android الإشعارات عبر اتصال محلي دوري/خدمة أمامية. وصولها عندما يكون التطبيق مغلقاً يعتمد على تشغيل خدمة Android وصلاحيات الإشعارات واستثناءات تحسين البطارية في الجهاز.

## الأمان
هذا إصدار تأسيسي للتطوير والاختبار داخل LAN. قبل التشغيل الفعلي يجب تغيير بيانات المدير، وتقييد الوصول إلى شبكة الإدارة، وإعداد HTTPS أو قناة موثوقة عند الحاجة. لا تفتح المنفذ 8080 على الإنترنت.
